# Wentao Li

I use AI to investigate open problems in mathematics and theoretical computer science. My research catalogue contains proof drafts and counterexamples, including work on Busy Beaver functions, weak forms of the axiom of choice, and language generation in the limit. Each draft links to the original question and includes the proof in PDF and LaTeX. The arguments and their priority await independent review.
